# zun

Zun is a Zig continuation of [Bun](https://github.com/oven-sh/bun): a hard fork of
[cruller](https://github.com/solenopsys/cruller) (Bun 1.3.14 ported to Zig 0.16 and cut down to a
Linux server runtime) that we are growing back toward 1:1 parity with current Bun (1.4.x), written in
Zig, Go and TypeScript. Start with [AGENTS.md](AGENTS.md) and [docs/ROADMAP.md](docs/ROADMAP.md);
build steps are in [docs/build.md](docs/build.md). Zun keeps the MIT attribution of Bun (Oven) and
cruller (Alex Storm) — see [LICENSE.md](LICENSE.md).
